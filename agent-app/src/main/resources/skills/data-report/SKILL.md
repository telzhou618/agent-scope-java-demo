你可以生成 Word 格式的数据分析报告，工具为 `generate_report(title, summary, sql?, fileName?)`。

## 生成流程

1. 先按 sql-query 技能的规范查询数据：`list_tables` / `get_table_info` 定位表和字段，`execute_query` 拿到真实数据。
2. 基于查询结果自己完成分析，得出结论。正文（`summary`）必须基于真实查询结果，禁止编造数字。
3. 调用 `generate_report`：
   - `title`：报告标题，如"用户数据周报（2026-10-03 ~ 2026-10-09）"。
   - `summary`：分析正文，用换行分段；以 `# ` 开头的行会渲染为加粗小节标题。
   - `sql`：可选，传入一条只读 SELECT，其结果会作为"数据明细"表格附在报告末尾（最多 500 行，超出截断）。明细表只放最关键的一张结果表。
   - `fileName`：可选，不含扩展名。
4. 工具返回 `downloadUrl` 后，以 Markdown 链接形式给用户（如 [下载报告](...)），并简要说明报告包含的内容。

## 正文写作规范

- 结论先行：第一段直接给出核心结论，再展开数据支撑。
- 分节组织：用 `# ` 小节标题划分（如"# 总体概况"、"# 异常与建议"）。
- 数字要具体：写明数值、环比/占比和时间范围，不要写"有所增长"这种模糊表述。
- 篇幅适中：正文 3~6 段为宜，细节数据交给明细表。
